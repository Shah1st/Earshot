# Earshot demo pack

Everything needed to run the five demo rides without the Python environment. Generated by
`ml/scripts/export_demo_pack.py`; do not edit by hand. The contract is in `docs/INTEGRATION.md`.

| Path | For | What |
|---|---|---|
| `config.json` | app | thresholds, GPS limits, wordless sound rule, judge model and system prompt (version 13) |
| `head.json` | app | sound head: 2,048 weights + bias |
| `models/yamnet_tfhub.tflite` | app | float YAMNet; outputs 521 class scores and a 1,024 value embedding |
| `models/yamnet_labels.txt` | app | class names, line i = class i |
| `models/vosk-model-small-en-us-0.15/` | app | Vosk speech model |
| `rides/<id>.wav` | Unity | full ride, 16 kHz mono PCM16: play it aloud and stream it in 0.5 s chunks |
| `rides/<id>.gps.jsonl` | Unity | one line per 0.5 s: `{"t", "lat", "lon", "speed_kmh"}`, send with the audio chunk of the same `t` |
| `scenarios/<id>.json`, `routes/`, `clips/` | Unity | the same rides as scenario files, if Unity mixes and drives itself |
| `expected/<id>.json` | both | decisions of the Python reference: the output format and the parity target |
| `expected_baseline/<id>.json` | app | what the always-listening audio LLM answered per chunk, with its token usage (comparison button) |

## Output format (`expected/<id>.json`)

A list of decisions, in time order:

```json
{"t": 29.0, "type": "decision", "decision": "alert", "source": "llm", "severity": 3,
  "reason": "Explicit demands to stop the car and get out indicate a serious safety threat.",
  "event_id": 1, "event": {"t": 24.0, "trigger": "sound", "groups": {}, "top_labels": {}, "gps": {},
  "keywords": [], "transcript": "..."}, "usage": {"total_tokens": 0}}
```

* `decision`: `dismiss`, `check_in` (ask the rider) or `alert` (silent operator alert).
* `source`: `llm` (judge call), `rule` (no LLM), `rule+summary`.
* `type`: `decision`, or `summary` (text added to an alert that a rule already raised).
* `event`: exactly the JSON that was sent to the judge (null for some rule outputs); `usage`: tokens the API reported.
* The app matches the reference if it produces the same decisions within about 0.5 s.
